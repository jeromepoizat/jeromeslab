# Frontend scaffold

The browser application will live here and use React, TypeScript, and Vite.
Milestone 0 will add generated package metadata and lock it only after the Node
package manager is available and the result can be verified. No frontend
application has been implemented yet.

The intended UI shell has:

- a header titled **Jerome's Laboratory**;
- a collapsible project sidebar;
- one vertically scrolling workflow page;
- a collapsible step-navigation rail; and
- a top-right Research Queue panel.

See `docs/ARCHITECTURE.md` and `docs/ROADMAP.md` for boundaries and sequencing.
